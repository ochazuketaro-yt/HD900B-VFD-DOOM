# トラブルシューティング

実行したディレクトリ(既定 `/tmp/vfd`)の `doom.log` に、DOOM の標準出力・標準エラーが残ります。

## `WAD not found`

`DOOM.WAD` が見つかりません。インストーラの `--wad` / `--wad-on-device` で置くか、`WAD=/path/DOOM.WAD ./doomvfd.sh` で指定してください。WAD は本プロジェクトに含まれません。

## 前面に何も出ない

1. `./doomvfd.sh` を実行して、数秒待ちます(DOOM のロードを待ってから表示を始めます)。 `doom.log` にエラーが出ていないか確認してください(WAD が壊れている、など)。
2. `/dev/venus_vfdo` と `/dev/venus_vfd_wrctl` があるか確認します(HD900B 以外では無い場合があります)。
3. 別の Telnet から `ps` で `fbdoom_vfd` と `vfdmux` が動いているか確認します。

## 表示が `HD900B` に戻らない

`/tmp/vfd/vfdctl pt HD900B` を実行します。それでも戻らなければ、電源を入れ直してください。

## キーが効かない / 別のキーボードを使いたい

1. `./find_keyboard.sh` で入力デバイスを一覧します。
2. `./evlog 10` を実行して(10 秒間)キーを押し、どの `eventN` に `val=1`/`val=0` が出るかを確認します。
3. `EVDEV=/dev/input/eventN ./doomvfd.sh` で指定します。

受信機(Logitech など)では、2 つのインターフェースが別々の `event` として見えることがあります。キー入力が出る側を使ってください。

## ホーム画面が同時に反応する

同じキー入力が純正の DvdPlayer にも届くことがあります。ホームの操作に使われないキー(WASD、テンキーなど)で操作してください。`FBDOOM_GRAB=1` で `EVIOCGRAB` を試せます(効果は未確認です)。

## ちらつく / 暗い

`vfdmux` のグループ数を 1 より大きくすると、ちらつきが出ます(既定は 1)。 CPU 負荷が高い場合は、ほかのプロセスを止めてみてください。

## 敵の点滅が見づらい

スマホなどで撮影すると、約 50Hz の点滅が撮影のフレームレートと干渉することがあります。`BLINK=2`(約 25Hz)や `BLINK=3` などを試してください。

## 電源を入れ直したら動かなくなった

`/tmp` に置いたファイルは電源を入れ直すと消えます。インストーラをもう一度実行してください。
