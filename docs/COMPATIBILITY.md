# 互換性

動作確認は **HiMedia HD900B 1 台**(Linux 2.6.34-VENUS、2011 年ビルドのファームウェア)のみです。

## 他の機種で試すとき

同じ Realtek RTD1186 系の機器でも、前面の表示 IC・デバイス名が異なる可能性があります。確認の目安:

1. `uname -a` が `Linux ... 2.6.34-VENUS ... mips` になる。
2. `/dev/venus_vfdo` と `/dev/venus_vfd_wrctl` がある。
3. 前面が 9 桁 × 5×7 ドットの VFD である(PT6302 系)。 ほかの種類(7 セグメントなど)では、そのままでは動きません。
4. `vfdctl pt ABCDEFGHI` で、前面に文字が出る。出なければ、本ツールは使えません。

インストーラは、1・2 の条件を満たさない場合に警告を出します。

動いた / 動かなかった報告(機種名、ファームウェア版、`uname -a`)を歓迎します。
